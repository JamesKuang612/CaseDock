# CaseDock 测试资产记录

CaseDock 约束测试资产如何保存，不接管 Agent 的测试判断。Agent 自行选择定位、等待、重试和判断方式；CaseDock Browser 只是在当前 Agent 没有交互式浏览器工具时提供的可选兜底。

## 找到资产库

从当前目录向上寻找 `casedock.yaml`。用户指定目录时优先使用该目录。若没有资产库但用户明确要求使用 CaseDock，在当前项目下创建 `casedock-tests/` 并运行 `casedock --root <目录> init`；创建后告诉用户实际位置。

读取 [资产格式](references/asset-format.md) 了解版本化内容与临时内容的边界。需要调用记录工具时再读取 [CLI 接口](references/commands.md)。

## 选择测试执行能力

执行 Web 或桌面 UI 测试前先检查当前任务已经加载的工具，不要通过漫长试错判断能力：

1. 用户明确指定执行工具时优先遵循。否则，若当前 Agent 已有能够实际点击、输入并保存截图的浏览器或计算机操作工具，使用该工具并保留其完整自主性；只能打开或展示网页标签不算交互能力。
2. 当前 Agent 没有合格的交互工具时，读取 [浏览器兜底](references/browser.md)，运行 `casedock doctor --json` 检查 CaseDock Browser。兜底已就绪时可以在当前对话直接使用，不需要安装 MCP 或切换对话。
3. 兜底未安装或首次启动失败时立即向用户说明原因和准确安装命令。未经用户同意不得下载浏览器、安装 MCP 或切换到其他测试产品；不得继续搜索无关 Skill，或为普通一次性测试临时生成并调试自动化脚本。
4. 用户不安装或当前 Agent 连终端也无法执行时，如实保存 blocked、error 或 interrupted（如果 run 已创建）并结束，不伪造操作和证据。

能力检查只决定使用哪种机械工具，不改变 Agent 对页面、步骤和断言的自主理解。

## 保留 Agent 的执行自由

- 将用例步骤视为业务检查点，不要把它改写成固定的鼠标点击脚本。
- 可以按页面实际情况增加内部操作、等待和恢复尝试；这些不需要成为新的业务步骤。
- 断言结论由实际观察决定。不要把页面当前行为改写成预期，也不要为了通过而降低证据要求。
- 缺少必要能力时如实记录 blocked、error 或 interrupted，不伪造浏览器操作和证据。

## 沉淀用例与运行

1. 用户提供新的表格、文档或自然语言测试需求时，不要列出、搜索、读取或比较资产库中的已有用例。将每条独立场景通过 `case create` 创建为全新用例，即使名称或内容与已有用例相同也不复用；Case ID 必须使用 CaseDock 返回的自动生成值。批量输入含 N 条独立场景时必须创建 N 条新用例。保留来源文件及行号等可追溯信息于标题、标签或操作描述中。
2. 只有用户明确要求重复执行某个 Case ID 时，才使用 `case get <case-id>` 读取该用例；不要读取其他用例，也不要创建新用例。找不到该 ID 时直接报告，不进行标题或语义匹配。每次重复执行仍创建新的 run，不覆盖历史。
3. 在执行浏览器操作前开始 run，使本次运行绑定固定用例快照。将用户提供的初始地址以及测试账号、测试密码原样写入 run；不需要登录时账密传 `null`。页面跳转后的地址写入步骤观察，不覆盖初始地址。测试账号和密码按普通测试数据处理，可以按用户要求写入资产。
4. Agent 自由执行一个业务步骤后，立即保存实际观察和与断言相关的截图，再继续下一步。不同 Agent 的内部操作可以不同，结果必须按用例中的 step ID 和 assertion ID 对齐。页面文本等信息直接写入观察，不另存为文本附件。
5. 通过断言必须提交用例要求的截图。失败也应尽量保存现场；无法取得截图时如实说明。截图先写到 `.casedock/inbox/`，登记后由 CaseDock 归档。
6. 正常结束、失败结束和中断都要 finish。由 CaseDock 根据已记录内容汇总结论并计算测试耗时；遗漏检查、证据不足或中断不能成为 passed。若宿主明确提供了本次测试的准确 Token 总量则一并记录来源和数值，无法取得时留空，禁止估算。批量任务结束前核对输入场景数、新建 Case ID 数和新建 run 数一致。

## 交付结果

完成后向用户报告资产库路径、用例 ID、run ID、最终结论和证据目录。提醒用户可运行 `casedock open` 在本地编辑器中复核，再决定是否提交 Git。CaseDock 只能校验格式与证据完整性，不能独立证明 Agent 的语义判断真实。
