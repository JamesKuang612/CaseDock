# CaseDock 测试资产记录

CaseDock 约束测试资产如何保存，不接管 Agent 的测试判断。Agent 自行选择定位、等待、重试和判断方式；CaseDock Browser 只是在当前 Agent 没有交互式浏览器工具时提供的可选兜底。

## 找到资产库

从当前目录向上寻找 `casedock.yaml`。用户指定目录时优先使用该目录。若没有资产库但用户明确要求使用 CaseDock，在当前项目下创建 `casedock-tests/` 并运行 `casedock --root <目录> init`；创建后告诉用户实际位置。

读取 [资产格式](references/asset-format.md) 了解版本化内容与临时内容的边界。测试结束准备保存时再读取 [CLI 接口](references/commands.md)。

## 选择测试执行能力

执行 Web 或桌面 UI 测试前先检查当前任务已经加载的工具，不要通过漫长试错判断能力：

1. 用户明确指定执行工具时优先遵循。否则，若当前 Agent 已有能够实际点击、输入并保存截图的浏览器或计算机操作工具，直接使用并保留其完整自主性；只能打开或展示网页标签不算交互能力。
2. 当前 Agent 没有合格工具且用户尚未明确选择 CaseDock Browser 时，在本次对话第一次准备启用兜底前必须暂停并询问：说明优先推荐安装该 Agent 官方支持的 Playwright MCP、浏览器插件或原生 Computer Use，通常集成更自然；安装后可能需要重启 Agent 或新开对话。让用户选择“先暂停并安装原生能力”或“继续使用 CaseDock Browser 兜底”。不要替用户静默选择。
3. 用户选择安装原生能力时停止当前测试，等待用户安装和重启后再继续。CaseDock 不代替宿主安装 MCP。用户明确选择兜底、已经在请求中指定兜底，或宿主根本不支持这类扩展时，才读取 [浏览器兜底](references/browser.md) 并检查 CaseDock Browser；同一对话内不重复询问。
4. 兜底未安装或首次启动失败时立即向用户说明原因和准确安装命令。未经用户同意不得下载浏览器、安装 MCP 或切换到其他测试产品；不得继续搜索无关 Skill，或为普通一次性测试临时生成并调试自动化脚本。
5. 用户不安装或当前 Agent 连终端也无法执行时，如实结束并说明能力缺口，不伪造操作、结论和证据。

能力检查只决定使用哪种机械工具，不改变 Agent 对页面、步骤和断言的自主理解。

## 保留 Agent 的执行自由

- 将用例步骤视为业务检查点，不要把它改写成固定的鼠标点击脚本。
- 可以按页面实际情况增加内部操作、等待和恢复尝试；这些不需要成为新的业务步骤。
- 断言结论由实际观察决定。不要把页面当前行为改写成预期，也不要为了通过而降低证据要求。
- 缺少必要能力时如实记录 blocked、error 或 interrupted，不伪造浏览器操作和证据。

## 执行与一次提交

1. 用户提供新的表格、文档或自然语言测试需求时，不要列出、搜索、读取或比较资产库中的已有用例。每条独立场景都作为全新用例，即使名称或内容相同也不复用。批量输入含 N 条独立场景时必须最终提交 N 条新用例。保留来源文件及行号等可追溯信息于标题、标签或操作描述中。
2. 开始实际测试时记住准确的 ISO 开始时间，不需要先调用 CaseDock 创建用例或 Run。Agent 自由执行测试，把每个业务步骤的观察和相关截图暂存到 `.casedock/inbox/`；页面文本和跳转地址直接写入观察，不创建文本附件。
3. 测试结束后读取 [CLI 接口](references/commands.md)，为每个独立场景生成一份提交清单并只调用一次 `casedock test submit`。CaseDock 自动生成 Case ID、step/assertion ID 和 Run ID，在正式落盘前统一校验，并把截图归档到最终 Run。不要再为普通新测试串联 `case create`、`run start`、`artifact add`、`run record` 和 `run finish`。
4. 通过断言必须在清单中引用真实截图。失败也应尽量保存现场；正常完成、失败、中断和工具错误都要如实提交。遗漏检查、证据不足或中断不能成为 passed。
5. 将用户提供的初始地址以及测试账号、测试密码原样写入清单；页面跳转后的地址只写入观察。若宿主明确提供本次测试的准确 Token 总量则记录来源和数值，无法取得时留空，禁止估算。
6. 只有用户明确要求重复执行某个 Case ID 时，才读取该 ID；不要读取其他用例，也不要进行标题或语义匹配。重复执行暂时使用 [CLI 接口](references/commands.md) 中的增量命令，并创建新的 Run，不覆盖历史。

## 交付结果

完成后向用户报告资产库路径、用例 ID、run ID、最终结论和证据目录。提醒用户可运行 `casedock open` 在本地编辑器中复核，再决定是否提交 Git。CaseDock 只能校验格式与证据完整性，不能独立证明 Agent 的语义判断真实。
