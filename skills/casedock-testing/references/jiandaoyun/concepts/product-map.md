# 简道云产品地图

## 最小心智模型

```text
工作台（全局首页）
├─ 应用搭建
│  └─ 应用
│     ├─ 普通表单：收集与协作数据
│     ├─ 流程表单：收集数据并按流程流转
│     ├─ 仪表盘：分析和展示数据
│     └─ 应用后台：应用设置、数据工厂、自动化等管理能力
├─ 流程中心：跨应用查看与处理本人相关流程
├─ 知识库：企业文档与知识共享
├─ AI 助理：快捷填报、知识问答等成员能力
├─ 开放平台：API、插件、开放市场等开发能力
└─ 账户中心 / 管理后台：个人与企业级设置
```

## 容易混淆的概念

- **工作台 vs 应用首页**：工作台是登录后的企业级首页；应用首页是某个应用内部优先展示的仪表盘。
- **管理后台 vs 应用后台**：管理后台管理企业、成员、权限和全局设置；应用后台只管理当前应用。
- **普通表单 vs 流程表单**：普通表单侧重数据收集与协作；流程表单还需要流程设定和审批流转。
- **流程中心 vs 表单数据管理**：流程中心以“我参与的流程”为中心；数据管理面向管理员查看和维护某张表单的全部数据。
- **智能助手 Pro vs AI 助理**：智能助手 Pro 是应用内自动化工作流；AI 助理是成员通过对话使用的全局提效入口。
- **开放平台 vs 开放市场**：开放平台是开发能力总入口；开放市场是其中查找和使用插件的区域。

## 判断当前层级

- 能看到企业内多个应用：通常在工作台。
- 左侧是当前应用的表单、流程表单和仪表盘目录：在应用内部。
- 出现“表单设计 / 流程设定 / 扩展功能 / 表单发布”：在表单编辑层。
- 出现版本信息、内部组织、管理员、企业设置：在企业管理后台。
- 出现密钥管理、API 调试、自建插件、开放市场：在开放平台。
