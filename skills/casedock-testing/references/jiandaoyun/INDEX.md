# 简道云测试知识索引

本目录用于帮助 Agent 快速判断“当前在哪一层、目标功能在哪一层、为什么入口不可见”。它不是简道云完整说明书，也不是固定点击脚本。

## 使用方式

1. 从用户目标中提取一至三个关键词。
2. 只读取下表命中的参考文件；不确定产品层级时先读产品地图。
3. 到达页面后以真实界面为准。入口不可见时先检查身份、权限、版本和企业配置，不要长时间盲点。
4. 官方文档与公司实测可能存在时间差；参考文件中的“公司环境观察”只代表已验证环境。

## 快速止损

- 页面与参考明显不一致：先依据可见文字、URL 和稳定页面区域重新判断层级。
- 目标入口完全不存在：检查当前账号身份与产品版本，必要时向用户说明缺少的权限，不把“不可见”判成产品故障。
- 遇到遮挡弹窗、引导层或版本提示：先处理遮挡，再判断主页面。
- 同名功能出现多个入口：选择离当前页面最近且权限足够的入口，不必机械返回首页。
- 连续两次进入错误层级：停止猜测，重新读产品地图或对应导航卡。
