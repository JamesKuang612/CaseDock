# 开放平台

## 入口与定位

从工作台左上角九宫格或产品切换按钮进入“开放平台”。公司当前环境已验证该入口。开放平台是 API、插件和开放市场等开发能力的总入口，不是工作台中的普通应用。

入口可见性和内部菜单受成员身份、版本和增购能力影响。找不到某个菜单时先核对权限，不要改从应用列表搜索。

## 高频任务

- API Key：开放平台 → 密钥管理 → 创建 API KEY。
- API 调试与参数：开放平台内查看开发文档、参数说明或 API 调试台。
- 自建插件：开放平台 → 开发者后台 → 自建插件 → 新建插件。
- 开放市场：开放平台 → 开放市场。
- 前端事件：实际配置入口位于表单编辑 → 表单属性 → 前端事件，不一定在开放平台页面内。
- 单点登录：企业级设置入口，不要在插件或应用设置里寻找。

## API 基础概念

- `app_id` 表示应用，`entry_id` 表示应用内的表单；二者组合可唯一定位表单。
- 官方 API 使用 HTTPS、JSON 和固定 API 域名；文件上传属于例外。
- API 新增、页面填报、Webhook、智能助手和流程触发之间存在行为差异。测试某项 UI 或业务联动时，不要未经说明用 API 替代。
