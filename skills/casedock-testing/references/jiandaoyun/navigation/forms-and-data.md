# 表单与数据管理

## 表单类型

- 普通表单：用于数据收集、修改、删除、导入导出和分权协作。
- 流程表单：在表单基础上增加流程设定，适合审批和多人按规则流转。

## 新建入口

- 空应用：进入应用后直接选择“新建表单”或“新建流程表单”。
- 非空应用：点击目录搜索框附近的加号，再选择表单类型。
- 两种表单通常都可创建空白表单或从 Excel 创建。

## 编辑层级

- 普通表单常见设置链：表单设计 → 扩展功能 → 表单发布。
- 流程表单常见设置链：表单设计 → 流程设定 → 扩展功能 → 表单发布。
- 前端事件常见入口：表单编辑 → 表单属性 → 前端事件。

## 数据管理

数据管理用于管理员查看和维护某张表单的全部数据，包括搜索、筛选、添加、导入导出、删除和回收站等。

常见入口：选择目标表单 → 设置/编辑 → 切换到“数据管理”。只有应用管理员可通过电脑端进入完整数据管理。

## 测试注意

- 用户要求“提交后在数据管理中验证”时，先在成员视图完成填报，再切换到管理员的数据管理视图核验。
- API 新增数据与页面填报的触发和校验行为并不完全相同，不能用 API 结果代替前端填报测试。
- 表单字段名称可能修改；开放接口中的字段 ID 通常是更稳定的技术标识，但 UI 测试仍应以当前标签和上下文定位。
