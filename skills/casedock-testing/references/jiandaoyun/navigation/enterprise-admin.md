# 企业管理

## 入口

从工作台右上角头像进入账户中心，再进入管理后台。管理后台处理企业级信息，不用于编辑某个具体应用。

## 主要区域

- 基础设置：产品中心、版本信息、企业信息、订单信息。
- 通讯录：内部成员、部门、角色和外部互联组织。
- 权限中心：系统管理员、普通管理员、管理组与权限查询。
- 管理工具：企业设置、产品设置、消息推送等。
- 日志与统计：登录日志、企业/产品操作日志和成员使用统计。

通讯录管理的常见路径：账户中心 → 管理后台 → 内部组织/通讯录。管理员设置的常见路径：管理后台 → 权限中心 → 管理员。

## 测试注意

- 先确认当前测试账号的管理员类型；普通成员看不到企业级设置是正常权限行为。
- 公共模式与钉钉、企业微信、飞书等集成模式的账号信息和管理员来源可能不同。
- 企业设置通常全局生效，执行有副作用的修改前确认测试范围，并在结果里记录修改前后状态。
- 测试“个人设置”时不要误入管理后台；个人设置同样从右上角头像进入。
