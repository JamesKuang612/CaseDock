# 仪表盘与数据工厂

## 仪表盘

仪表盘用于查看、分析和处理应用数据。数据源可以来自普通/流程表单、数据流输出表或聚合表，不同图表支持的数据源范围不同。

常见创建入口：进入应用后点击目录搜索框附近的加号，或在空应用中直接选择仪表盘。编辑已有仪表盘时，可通过目录项设置菜单中的“编辑仪表盘”或页面右上角编辑入口进入。

测试图表前先核对数据源、筛选条件和当前成员的数据权限，避免把“无数据权限”误判成“统计错误”。

## 数据工厂

数据工厂负责加工多个表单的数据。数据流可以连接、追加合并、分组汇总、筛选、设置字段和行转列，并产生供仪表盘使用的输出表。

常见入口：进入目标应用 → 应用后台 → 数据工厂 → 新建数据流。

## 常见误区

- 数据工厂不是仪表盘里的一个图表，也不在企业管理后台。
- 仪表盘显示空白时，要分别检查源表数据、数据流运行结果、筛选和权限。
- 页面看到的是数据流输出表名称，不一定等于源表名称。
