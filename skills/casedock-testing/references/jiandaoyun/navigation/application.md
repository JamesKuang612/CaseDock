# 应用与应用后台

## 新建和进入应用

- 在工作台的“我的应用”区域查找或搜索目标应用。
- 有权限时可在工作台点击“新建应用”，选择空白应用、模板或其他创建方式。
- 进入应用后，左侧通常展示表单、流程表单、仪表盘和分组。

## 空应用与非空应用

- 空应用通常直接展示“表单、流程表单、仪表盘”的创建入口。
- 已有内容的应用通常从目录搜索框附近的加号创建新内容。
- 应用目录中的图标可辅助识别：普通表单、流程表单和仪表盘使用不同类型或颜色的图标，但应同时核对文字。

## 应用后台

应用后台是当前应用的管理层，通常位于应用侧边栏左下角。常见内容包括应用设置、数据工厂和应用级高级能力。只有拥有应用管理权限的账号才能看到或进入。

应用首页的常见路径：进入目标应用 → 应用后台 → 应用设置 → 应用首页。

## 常见误区

- 企业“管理后台”不负责编辑某个具体应用；不要为了找数据工厂进入企业管理后台。
- 工作台上的应用设置按钮主要用于修改应用信息；应用内部的应用后台包含更完整的应用级设置。
- 找不到应用时先使用工作台搜索，并确认当前企业和账号权限。
