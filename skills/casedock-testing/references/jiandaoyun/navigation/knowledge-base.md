# 知识库

## 入口

在工作台左上角点击九宫格或产品切换按钮，选择“知识库”。进入后只会看到当前成员有权限访问的知识库。

有权限时，可在知识库页面右上角创建知识库。进入单个知识库后，可创建、导入、发布和管理文档；知识库管理入口通常位于知识库卡片菜单或单个知识库页面左下角。

## 权限与版本

- 知识库属于可能需要增购的能力；没有对应版本时，普通成员可能无法访问。
- 创建者、系统管理员、知识库管理员和普通成员的创建、管理与阅读权限不同。
- 看不到某个知识库时先确认阅读权限，不要只按名称反复搜索。

## AI 知识问答

知识库文档可以作为 AI 助理“知识问答”技能的知识范围。常见配置路径为：管理后台 → 企业设置 → AI 能力 → AI 助理设置 → 知识问答 → 添加知识库。

测试时应分别验证：知识库内容是否发布、当前成员是否有阅读权限、AI 是否完成学习，以及回答是否基于授权范围。
