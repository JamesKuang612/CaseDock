# 开发计划

## 0. 开发基线

- Git main 分支、工程约定和文档。
- TypeScript、CLI、Fastify、本地 React 界面。
- 依赖锁定、类型检查和生产构建。

## 1. 内核与第一个执行闭环

本轮已实现：Schema、版本检查、原子写入与互斥锁、运行快照、幂等记录、证据登记、结果汇总、执行 Skill。内核/CLI/API 共 12 项测试通过。

- TestCase / Run / Artifact Schema 和稳定 ID。
- YAML 读取与校验；文件原子写入、版本冲突检测。
- run start / record / finish 与证据导入。
- 用例快照、结果完整性校验、幂等记录。
- 独立编写团队执行 Skill，使用 Agent 已有的浏览器工具。
- 内核测试：缺失证据、执行中断、版本漂移、重复提交和路径越界。

## 2. 可用的编辑器

已实现：用例列表与搜索、结构化编辑（步骤上下移动）、版本冲突提示、运行历史与证据、复制执行指令、每 4 秒轮询更新。真实浏览器流程测试通过。拖动排序、SSE 通知和运行包分享留待后续。

- 用例库与结构化编辑。
- 执行历史、逐步断言和截图查看。
- 文件更新通知及编辑冲突提示。
- 复制执行指令和运行包分享。

## 3. 团队验证

尚未完成两位同事/两种独立 Agent 的实际协作验收；当前验证仅证明本工具的内核、CLI 和界面链路。

- 两位同事通过 Git 共享同一用例。
- 两种不同 Agent 分别执行并输出可统一读取的结果。
- 人为缺陷产生失败证据；Agent 中断保留部分结果。
